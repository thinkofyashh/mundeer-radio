# Scene artwork

The road-trip experience keeps its changing illustration paths in the `chapterImages` list inside `components/NostalgiaExperience.tsx`.

Replace `scene1-street.jpg` or add similarly optimized JPG/WebP files in `memories/`, then update that list. Recommended dimensions are 2000×1125 for landscape scenes and 1400×1400 for square memory scenes. Keep each production image below roughly 1 MB where possible.
