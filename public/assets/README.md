# Scene artwork

The road-trip experience keeps its changing illustration paths in the `chapterImages` list inside `components/NostalgiaExperience.tsx`.

`hero-car-v3.jpg` is the optimized 2000×1125 opening scene. Add similarly optimized JPG/WebP files in `memories/`, then update the chapter list. Recommended dimensions are 2000×1125 for landscape scenes and 1400×1400 for square memory scenes. Keep each production image below roughly 1 MB where possible.
